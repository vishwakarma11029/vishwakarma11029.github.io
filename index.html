How I run infrastructure

The same five steps on every system, whether it is a single server or a client tenant.

  1. 1

    Build

    Provision VMs, tenants and containers to the requirement, with resources sized to the SLA.

  2. 2

    Secure

    Harden the OS, patch kernels, lock down SSH and write firewall policies.

  3. 3

    Watch

    Track health and resource use with Zabbix, Nagios and CloudWatch.

  4. 4

    Protect

    Back up with Veeam, Acronis and snapshots, stored on S3 where the plan calls for it.

  5. 5

    Prove recovery

    Validate restores so DR readiness is tested, not assumed.
