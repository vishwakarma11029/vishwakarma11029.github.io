Confirm service state, recent logs and whether the service is enabled at boot.

Open commands

Network

Interface Down Troubleshooting

Useful first checks when a Linux NIC unexpectedly shows DOWN or loses connectivity.

Open commands
ip -br link
ip -br addr
ethtool NIC
ethtool -S NIC | egrep -i 'err|drop|timeout|fail'
dmesg -T | grep -iE 'NIC|link|down|up|timeout|reset'
journalctl -k --since "30 min ago" --no-pager
Replace NIC with the interface name, for example eth0 or ens192.

Veeam

Veeam Job Failure First Checks

Initial checks when a job cannot allocate processing resources or a proxy/repository is unavailable.

Open checklist
1. Check VBR console → Infrastructure.
2. Confirm proxy status and version.
3. Confirm repository availability and free space.
4. Check gateway / cloud repository connectivity.
5. Review job session logs.
6. Check recent network / firewall / IPsec events.
7. Retry only after the failed dependency is healthy.
Acronis

Backup Space Troubleshooting

First checks when an Acronis workload reports insufficient free space.

Open checklist
1. Check appliance free space.
2. Check backup destination capacity.
3. Review retention and backup schedule.
4. Check concurrent workload activity.
5. Identify the largest protected workloads.
6. Review the failed job details.
7. Re-run after capacity is restored.
Backup / DR

Backup Incident Checklist

A practical sequence for production backup failures.

Open checklist
1. Record job name and failure time.
2. Check network reachability.
3. Check firewall / VPN / IPsec.
4. Check proxy / agent state.
5. Check repository capacity.
6. Check service and application logs.
7. Confirm recovery point availability.
8. Document root cause and corrective action.
